Abstract

This work presents Controllable Layer Decomposition (CLD), a method for achieving fine-grained and controllable multi-layer separation of raster images. In practical workflows, designers generate and edit each RGBA layer independently before compositing them into a final raster image. However, this process is irreversible: once composited, layer-level editing is no longer possible. Prior works either adopt a two-stage pipeline based on image matting and inpainting, or specify the number of layers and let a DiT generate all layers end-to-end in a single pass; none of these approaches can jointly balance decomposition quality, efficiency, and controllability.

To address these challenges, we propose two key modules: LayerDecompose-DiT (LD-DiT), which decouples image elements into distinct layers and enables fine-grained control; and the Multi-Layer Conditional Adapter (MLCA), which injects target image information into multi-layer tokens to achieve precise conditional generation. To enable a comprehensive evaluation, we build a new benchmark and introduce tailored evaluation metrics. Experimental results show that CLD consistently outperforms existing methods in decomposition quality, efficiency, and controllability. Furthermore, the separated layers can be directly manipulated in commonly used design tools such as PowerPoint.

Method

Boxes make an ill-posed problem controllable

The same raster image can be explained by infinitely many layer stacks. A bounding box is the cheapest way for a designer to say which explanation they want — and it is what lets CLD generate each layer inside its own region instead of at full resolution.

1

Region-aware tokens

Each layer is generated only inside its box, cutting the dominant cost from a global O(N·HW) to a local O(∑HiWi). That is why 37 layers still fit on one GPU.

2

Aligned conditioning

MLCA beats cross-attention and shared-KV injection by a wide margin (28.8 vs 14.8 PSNR), because additive, box-aligned guidance preserves the tight spatial correspondence each layer needs.

3

Dual-condition CFG

The unconditional branch keeps the image and drops only the text. This anchors both branches to the same layout and stops background colour from leaking into foreground layers.

    Efficiency

    Cost grows with content, not with canvas count

    Full-resolution multi-layer models pay for every layer at H×W. CLD pays only for the boxes, so the curve stays almost flat where the baseline runs out of memory.
